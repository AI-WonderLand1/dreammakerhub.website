## WonderSpace buttons

- Create IDE creates an approved private Coder workspace for the current AI WONDERLAND project or a blank workspace.
- Open IDE opens the saved code-server app when Coder reports it ready.
- Edit resources changes the approved machine profile.
- Delete deletes the exact owned workspace and only releases the saved allocation after Coder confirms deletion.
- Current customer profiles are Micro (1 CPU / 2 GiB) and Standard (2 CPU / 4 GiB).
- The current Google Docker template does not expose GPU/VRAM controls.

## Connected services

| Service | Role |
| --- | --- |
| Supabase / Postgres | Auth, project data, realtime data, files/revisions, usage/billing records |
| Stripe | Memberships and configured credit packs |
| Coder | Private cloud IDE control plane |
| Google Cloud | Current Coder workspace compute host/template |
| OpenRouter + configured AI providers | Model routing and AI features |
| PlayCanvas | 3D/editor integration |
| Mem0 + MongoDB | Optional server-side semantic/durable memory |
| n8n | Optional automation/webhook integration |
| Resend / Twilio | Optional email/SMS usage alarms |
| GitHub / GHCR | Source, PRs, CI/security checks, container images; not arbitrary customer IDE repository input |

## Repository ownership

- dreammakerhub.website: main website/account/project shell, WonderBuild, WonderSpace, main 3D hub, central billing/usage/provider settings.
- AI-PLAYGROUND: multi-model chat, model directory, agents, workflow canvas/templates, provider routing.
- NPC-AI-SIM: NPC cognition authoring: brain, personality, memory, perception, knowledge, voice, actions, training, export/runtime contracts.
