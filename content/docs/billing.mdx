## Subscription Management

### Upgrade Plan
```bash
POST /api/billing/upgrade
{
  "planId": "enterprise"
}
```

### Cancel Subscription
```bash
POST /api/billing/cancel
```

### Get Current Plan
```bash
GET /api/billing/plan
```

## Webhooks

Configure Stripe webhooks for:
- `invoice.payment_succeeded`
- `invoice.payment_failed`
- `customer.subscription.deleted`
- `customer.subscription.updated`

Webhook endpoint: `https://your-domain.com/api/webhooks/stripe`

## Invoices

Download invoices from the dashboard or via API:
```bash
GET /api/billing/invoices
```

## Refunds

Request refunds within 7 days via support. Enterprise contracts have custom terms.
