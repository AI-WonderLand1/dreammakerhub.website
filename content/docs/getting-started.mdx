# Getting Started

Learn how to set up your environment, install dependencies, and start building with AI Wonderland.

## Prerequisites

- Node.js 20.19+
- pnpm (recommended) or npm
- Git

## Installation

```bash
# Clone the repository
git clone https://github.com/AI-WonderLand1/dreammakerhub.website.git
cd dreammakerhub.website

# Install dependencies
pnpm install

# Set up environment variables
cp apps/web/.env.example apps/web/.env
# Edit .env with your keys

# Start development server
pnpm dev
```

## Project Structure

```
dreammakerhub.website/
├── apps/
│   └── web/              # Next.js application
├── packages/
│   └── gesture-engine/   # Gesture recognition package
├── supabase/
│   └── functions/        # Edge functions
└── infra/                # Infrastructure configs
```

## First Steps

1. **Create an account** - Sign in or register at `/public-pages/auth`.
2. **Open Projects** - Your authenticated home is `/dashboard/projects`.
3. **Choose what you are building** - Use `/wonder-build` for websites/apps, `/wonderspace` for code, or `/dashboard/3dhub` for 3D.
4. **Build and finish** - WonderBuild follows **Start → Build (+ Preview) → Publish** instead of exposing separate AI-builder and preview routes.

## Environment Variables

| Variable | Description | Required |
|----------|-------------|----------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL | Yes |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon key | Yes |
| `SUPABASE_SERVICE_ROLE_KEY` | Service role key (server) | Yes |
| `STRIPE_SECRET_KEY` | Stripe secret key | For billing |
| `CEREBRAS_API_KEY` | Cerebras API for AI | Optional |
| `HUGGINGFACE_TOKEN` | HuggingFace token | Optional |
