# GitGenie

GitGenie is an AI-powered GitHub App that helps you manage your repositories, review pull requests, and keep your code context up-to-date.

## Features

- **AI-Powered PR Reviews:** Get intelligent feedback on your pull requests.
- **Repository Context:** GitGenie understands your codebase, commits, and PR history.
- **Automated Context Updates:** Automatically updates AI context when you push new code.
- **Customizable Personas:** Choose from different AI personalities to suit your workflow.

## Getting Started

1. **Install GitGenie:** Click the "Install" button on the GitHub Marketplace.
2. **Connect Database:** Connect your Firebase account to store repository memories and chat history.
3. **Configure API Key:** Add your Gemini API key in the app settings.
4. **Start Coding:** GitGenie will automatically start analyzing your repositories.

## Billing

GitGenie offers a Pro subscription for advanced features. You can upgrade to Pro in the app settings.
