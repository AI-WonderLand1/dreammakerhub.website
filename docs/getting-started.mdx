# Getting Started

Welcome to **AI‑Wonderland**! This guide walks you through setting up your development environment.

## Prerequisites
- Node 20 (Alpine base)
- Docker (optional for local builds)
- A Supabase account for authentication

## Install dependencies
```bash
npm install
```

## Run the dev server
```bash
npm run dev
```

The app will be available at `http://localhost:3000`.
