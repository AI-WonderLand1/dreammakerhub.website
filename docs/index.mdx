# AI WONDERLAND Documentation

This documentation is written for people using the website, not only for developers.

Start with the full [AI WONDERLAND User Guide](./USER_GUIDE.md). It explains:

- how to move through the website
- what the major buttons and tabs do
- how WonderBuild, WonderSpace, AI Playground, WonderPlay, and NPC-AI-SIM fit together
- which outside services can be connected
- which features belong to each repository
- which capabilities are live, gated, optional, or configuration-only

## Product map

| Product | Primary use | Repository |
| --- | --- | --- |
| WonderBuild | Website and web-app creation | dreammakerhub.website |
| WonderSpace | Project files, versions, and private Coder IDEs | dreammakerhub.website |
| AI Playground | Models, chat, agents, workflows, templates | AI-PLAYGROUND |
| WonderPlay / 3D Hub | 3D scenes, assets, generation, PlayCanvas-related tools | dreammakerhub.website |
| NPC-AI-SIM | NPC brain/cognition authoring | NPC-AI-SIM |
| Billing / usage | Memberships, AI credits, 3D credits, alerts | dreammakerhub.website |
