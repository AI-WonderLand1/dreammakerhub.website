# AI Wonderland Builder CLI

The official CLI for managing AI Wonderland projects.

## Installation

```bash
npm install -g .
```

## Usage

```bash
aiw <command> [options]
```

## Commands

- `aiw init`: Initialize a new AIW builder project
- `aiw new <project>`: Create a new AIW builder project directory
- `aiw build`: Build the project
- `aiw --help`: Show help

## Development

```bash
npm run dev -- <command>
```
