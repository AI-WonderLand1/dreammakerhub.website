# Support

DreamMakerHub.website is developed by **AI WONDERLAND INNOVATION**.

Use the contact that matches the request:

- **Product, account, billing, refunds, and technical support:** support@dreammakerhub.website
- **General questions and product feedback:** hello@dreammakerhub.website
- **Business, partnerships, careers, legal, and privacy:** contact@dreammakerhub.website
- **Security vulnerabilities and security-sensitive reports:** security@dreammakerhub.website

## Before contacting support

Include the repository or product area, the affected URL or feature, steps to reproduce the problem, and relevant error text. For code issues, include the branch or commit when known.

Please redact passwords, API keys, session tokens, private keys, database credentials, customer data, and other secrets from screenshots, logs, issues, and email.

## Security reports

Do not post exploitable vulnerabilities, credentials, or private customer information in a public GitHub issue. Use GitHub private vulnerability reporting when available or email security@dreammakerhub.website.

See [SECURITY.md](SECURITY.md) for the full security policy.
